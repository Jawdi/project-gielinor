description=Project Gielinor brings the world of Old School RuneScape into Project Zomboid.
description=
description=We're building a survival experience where you can explore familiar towns, gather resources, develop skills and equip RuneScape gear while facing Zomboid's hunger, injuries, weather and zombies.
description=
description=
description=[hr][/hr]
description=
description=[img]https://i.imgur.com/iiL2vWt.png[/img]
description=
description=[b]Project Gielinor is still in early development. The vision below describes where we're taking the project; some systems remain planned or incomplete.[/b]
description=
description=Expect bugs, unfinished features and visual glitches. Start a new world after each update. We haven't tested compatibility with other mods.
description=
description=
description=[hr][/hr]
description=
description=[img]https://i.imgur.com/VGsUf25.png[/img]
description=
description=We want Gielinor to feel like a world you can live in, explore and struggle to survive.
description=
description=[list]
description=[*][b]A familiar world.[/b] Explore RuneScape's towns, wilderness and landmarks for shelter and supplies.
description=
description=[*][b]RuneScape progression.[/b] Gather resources, develop skills and craft equipment to help you survive.
description=
description=[*][b]Equipment worth finding.[/b] Discover RuneScape weapons, armour and tools with useful roles in survival.
description=
description=[*][b]The inhabitants of Gielinor.[/b] Encounter RuneScape creatures and wildlife with behaviours suited to the world.
description=
description=[*][b]Zomboid survival.[/b] Manage hunger, injuries, exhaustion and weather while keeping zombies at bay.
description=[/list]
description=

description=[*]Project Zomboid Build 42.
description=
description=[*][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url], including its Java component. Follow the installation instructions on its Workshop page.
description=
description=[*]An internet connection for the initial setup.
description=[/list]

description=[img]https://i.imgur.com/EggpoAk.png[/img]
description=
description=[olist]
description=[*]Subscribe and enable Project Gielinor. This also enables ZombieBuddy.
description=
description=[*]Allow Project Gielinor to run its Java code when ZombieBuddy prompts you. You only need to approve this once.
description=
description=[*]At the main menu, follow the prompt to build the content pack.
description=
description=[*]Allow about 20 minutes for the first build on a fast PC, longer on slower ones. The build window shows each step and the time left. Once it finishes, the mods reload with the content pack enabled.
description=
description=[*]Start a new game and choose [b]Gielinor[/b] at World Select.
description=[/olist]
description=
description=The builder downloads about 190 MB of game files from the OpenRS2 archive, then draws the items and the whole world map on your computer. RuneScape's art belongs to Jagex, so we can't ship it; building it locally is what lets the mod exist. This only happens once, and again only when an update changes the map. World loading can also take a while.
description=
description=This mod does not include Jagex's files. Keep downloaded game files and generated content packs on your computer. Please don't share or upload them.
description=
description=
